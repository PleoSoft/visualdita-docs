# Visual DITA user guide

Visual DITA opens your DITA content in VS Code as a page you write on, the way you write in Word, while the files
stay DITA: valid, lossless, yours.

![A topic open in Visual DITA: the DITA Map view on the left, the page with its ribbon in the middle, the Properties, Review and Topic panes on the right](images/page.png)

> **Standard DITA is free.** Every feature — the page editor, maps, tables, review, comparisons with Git, the checks
> and the agent tools — works on the standard OASIS DITA document types, on any number of computers, for any use,
> commercial authoring included.
>
> **Your own document types** — specializations and constraints — are supported too: they come from Pleosoft as a
> licensed Visual DITA package, and that licence is the paid part. See [Your document types](document-types.md).
